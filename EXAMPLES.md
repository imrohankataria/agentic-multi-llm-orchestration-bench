## Generated Visualizations

### 1. Agent Timeline (timeline.html)
Interactive Plotly timeline showing:
- Each agent's activities over time
- Cost represented by marker size
- Hover for detailed information (cost, tokens, duration, model)
- Color-coded by agent

**Features:**
- Zoom and pan
- Interactive hover tooltips
- Cost overlays (larger markers = higher cost)
- Time-based analysis

### 2. Cost Breakdown Pie Chart (breakdown.html)
Shows cost distribution across agents:
- Percentage and dollar value for each agent
- Red highlighting for cost spike agents
- Interactive hover details

**Key Information:**
- Which agent consumes most resources
- Relative cost proportions
- Cost spike identification (red sections)

### 3. Event Type Analysis (events.html)
Stacked bar chart showing:
- LLM calls per agent (teal)
- Tool calls per agent (coral)
- Agent steps per agent (purple)

**Insights:**
- Activity patterns by agent
- Where time is spent
- Agent behavior comparison

### 4. Workflow Comparison Dashboard (comparison.html)
Multi-panel dashboard with:
- Total cost comparison bar chart
- Total events comparison
- Cost distribution box plots
- Summary metrics table

**Use Cases:**
- Compare CrewAI vs LangGraph
- Compare different configurations
- Identify optimization opportunities
- Track improvements over time

## Understanding the Metrics

### Cost
- Calculated from token usage × model pricing
- Includes input and output tokens
- Based on current market rates

### Tokens
- Input tokens: Prompt + context
- Output tokens: Model response
- Total tokens: Sum of both

### Duration
- Measured in milliseconds
- Includes API latency
- Useful for performance optimization

### Events
- **LLM Call**: Each API call to language model
- **Tool Call**: Each external tool invocation
- **Agent Step**: Each high-level agent action

### Spike Detection
- Compares each agent to average
- Default threshold: 2x average cost
- Identifies outliers automatically
- Helps focus optimization efforts

## Tips for Using Visualizations

1. **Timeline**: Look for clustering of expensive calls
2. **Pie Chart**: Focus optimization on largest slices
3. **Event Analysis**: Balance LLM calls vs tool calls
4. **Comparison**: Run same workflow multiple times
5. **Reports**: Share with team for cost discussions
